# Clinical Engine

## Objetivo

Transformar dados biomecânicos e clínicos em achados úteis para apoio à decisão fisioterapêutica.

## Escopo do MVP

- interpretar assimetrias;
- registrar dor;
- organizar achados por região corporal;
- permitir validação profissional;
- gerar linguagem clínica para relatório.

## Princípio de segurança clínica

O Clinical Engine não fecha diagnóstico médico.

Ele organiza evidências, achados e hipóteses para o fisioterapeuta validar.

## Núcleo de raciocínio

Paciente -> Avaliação -> Mídia -> Landmarks -> Métricas -> Achados -> Validação -> Relatório -> Evolução.

## Saída esperada

- achado clínico estruturado;
- severidade;
- região corporal;
- justificativa;
- necessidade de validação profissional;
- recomendação de acompanhamento.
