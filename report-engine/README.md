# Report Engine

## Objetivo

Gerar relatórios evolutivos claros para fisioterapeutas e pacientes.

## Conteúdo mínimo do relatório

- dados do paciente;
- data da avaliação;
- tipo de avaliação;
- queixa principal;
- escala de dor;
- imagens ou frames relevantes;
- métricas biomecânicas;
- achados clínicos;
- validação profissional;
- plano sugerido;
- comparação evolutiva.

## Regra

Relatório final precisa de validação do fisioterapeuta.

## Exportação

MVP: PDF simples.

Futuro: relatório interativo, dashboard do paciente e comparação longitudinal.
