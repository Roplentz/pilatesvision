# Prompt cirurgico — corrigir rotas internas no Lovable

Use este prompt no Lovable quando a landing e a pagina Alunos existirem, mas faltarem as demais paginas internas.

```text
Corrija a estrutura de paginas do app.

Atualmente existem apenas a landing page e a pagina Alunos. Preciso que o app tenha todas as paginas internas do SaaS navegaveis.

Nao refaca o design inteiro.
Nao crie backend.
Nao conecte Supabase.
Nao implemente IA real.
Nao implemente upload real.
Nao implemente PDF real.
Use apenas dados mockados.
Mantenha o visual dark premium ja criado.
Apenas organize navegacao, rotas e paginas internas.

IMPORTANTE:
Troque qualquer nome temporario por PilatesVision em todo o app.

Nova marca:
PilatesVision

Tagline:
Movimento inteligente para clinicas de Pilates

Badge:
Pilates 5.0

Crie uma estrutura com duas areas:

1. Area publica
- Landing page
- Botoes: Entrar e Comecar
- Ao clicar em Entrar ou Comecar, ir para o app interno mockado

2. Area interna do SaaS
Deve ter sidebar fixa ou menu interno com estas paginas:

- Dashboard
- Alunos
- Nova Avaliacao
- Avaliacao Postural
- Avaliacao Dinamica
- Exercicios Pilates
- Relatorios
- Configuracoes

Todas as paginas precisam abrir ao clicar no menu.
Nao pode haver tela branca.
Nao pode haver link quebrado.

Pagina Dashboard:
- Titulo: Dashboard
- Subtitulo: Visao geral da clinica
- Cards: Alunos ativos, Avaliacoes realizadas, Relatorios gerados, Evolucao media
- Lista de alunos recentes
- Bloco: Proximas reavaliacoes
- Botao: Nova avaliacao

Pagina Alunos:
Manter a pagina atual de alunos.
Manter busca, cards dos alunos, botao Novo aluno e botao Voltar.
O botao Voltar deve voltar para o Dashboard interno.

Pagina Nova Avaliacao:
Criar jornada com progress tracker:
Ficha -> Postural -> Dinamica -> Exercicios -> Relatorio

Pagina Avaliacao Postural:
Criar cards para Vista anterior, Vista lateral e Vista posterior com resultados mockados.

Pagina Avaliacao Dinamica:
Criar selecao de movimento e resultados mockados.

Pagina Exercicios Pilates:
Criar biblioteca com cards de exercicios.

Pagina Relatorios:
Criar lista de relatorios mockados e visualizacao de relatorio.

Pagina Configuracoes:
Criar cards para dados da clinica, profissionais, preferencias de relatorio, termo de consentimento, politica de privacidade e plano atual.

Criterio de aceite:
Landing abre.
Entrar leva ao Dashboard.
Dashboard abre.
Alunos abre.
Nova Avaliacao abre.
Avaliacao Postural abre.
Avaliacao Dinamica abre.
Exercicios Pilates abre.
Relatorios abre.
Configuracoes abre.
Nenhuma pagina fica em branco.
Nome PilatesVision aparece em todo lugar.
```
